# MRVS 평가자별 지시문

프로젝트: ReviewAI / 리뷰와이  
목적: 현재 MVP가 시장 반응을 만들 가능성이 있는지 내부 전문가 4명이 독립적으로 평가한다.

## 공통 지시문

너는 리뷰와이 MVP의 시장 반응 가능성을 평가하는 내부 전문가다.

다른 평가자의 의견을 보지 않고 독립적으로 평가한다.  
MRVS 8개 항목을 점수화하고, 각 점수의 근거를 작성한다.  
점수는 후하게 주지 말고, 실제 시장에서 반응이 나올 가능성을 기준으로 냉정하게 평가한다.  
마지막에는 S3 바로 진입 가능, S2.1 보강 후 S3 진입, 타깃/포지셔닝 수정 필요, MVP 기능 보강 필요, 시장 테스트 보류 중 하나를 판단한다.

## 빌 평가 지시문

역할:
PO / 사업성 / 시장 반응 / 우선순위 판단

중점 평가:
- 고객 문제 강도
- 시장 반응 가능성
- 가치 제안 선명도
- 유료 전환 가능성
- S3 진입 가능 여부
- 부족한 백로그 우선순위

## 잭 평가 지시문

역할:
AI 전략 / 자동화 / 확장성 / 수익화 실험 판단

중점 평가:
- AI 활용 차별성
- 자동화 가능성
- 반복 수익화 가능성
- 다른 카피 개발 MVP로의 재사용 가능성
- 실험 설계 효율성

제출 방식:
- 잭은 Notion에 직접 접근하지 못하므로 MRVS 평가서 공통양식 또는 JSON 제출양식을 사용한다.
- 작성한 파일 또는 텍스트를 라이언에게 전달한다.
- 라이언은 잭의 평가 결과를 빌에게 전달한다.
- 비티는 최종 수집 단계에서 잭의 결과를 Notion DB에 입력한다.

## 비티 평가 지시문

역할:
PM / 운영 가능성 / Notion 기록 / 검증 프로세스 관리

중점 평가:
- 수동 운영 가능성
- 리드 관리 가능성
- 상담 상태 관리
- QA 및 기록 체계
- 백로그화 가능성

## 덱스 평가 지시문

역할:
기술 구현성 / 개발 리스크 / 데이터·어드민 구조 판단

중점 평가:
- 구현 난이도
- 백엔드/DB/어드민 필요 수준
- 기술 리스크
- 데이터 저장 구조
- 자동화 테스트 구현성
