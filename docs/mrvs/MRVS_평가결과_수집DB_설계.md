# MRVS Evaluation Results DB 설계

DB 이름:
MRVS Evaluation Results

## 필드 설계

| 필드명 | 타입 | 설명 |
|---|---|---|
| 평가명 | Title | 예: Jack - ReviewAI MRVS 1차 평가 |
| 평가자 | Select | 빌 / 잭 / 비티 / 덱스 |
| 역할 관점 | Select | PO / AI전략 / PM운영 / 기술구현 |
| 총점 | Number | 100점 만점 |
| 문제 강도 | Number | 15점 |
| 타깃 선명도 | Number | 10점 |
| 가치 제안 | Number | 15점 |
| 행동 전환 | Number | 15점 |
| 지불 의사 | Number | 15점 |
| 신뢰/품질 | Number | 10점 |
| 운영 가능성 | Number | 10점 |
| 확장/반복 가능성 | Number | 10점 |
| 핵심 근거 | Text | 총점의 근거 |
| 가장 큰 리스크 | Text | 1~3개 |
| 추천 백로그 | Text | 필요한 후속 백로그 |
| S3 진입 판단 | Select | 바로 진입 / 조건부 / 보류 / 포지셔닝 수정 / 시장 테스트 보류 |
| 작성 상태 | Select | 대기 / 제출 / 보완 필요 / 확정 |
| 제출 원본 | Files & media 또는 URL | 잭 등 외부 제출 파일 첨부용 |
| 작성일 | Date | 제출일 |

## 보기 구성

- 전체 평가 결과
- 평가자별 보기
- S3 판단별 보기
- 보완 필요 항목
- 확정 평가

## 운영 주의

- 원본 제출 내용은 삭제하지 않는다.
- 잭처럼 Notion 접근이 어려운 평가자는 제출 원본 필드에 파일을 첨부한다.
- 비티가 입력하되, 빌 종합 전에는 점수를 임의로 수정하지 않는다.
- 수정이 필요하면 작성 상태를 보완 필요로 바꾼다.
