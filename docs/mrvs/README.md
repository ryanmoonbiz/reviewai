# MRVS 검증체계 문서 패킷 v0.1

포함 파일:

- MRVS_검증운영_지침서.md
- MRVS_평가서_공통양식.md
- MRVS_평가서_JSON_제출양식.md
- MRVS_평가자별_지시문.md
- MRVS_Notion_편집가이드.md
- MRVS_평가결과_수집DB_설계.md

사용 순서:

1. 비티가 검증운영 지침서를 기준으로 Notion 페이지 생성안을 작성한다.
2. 잭처럼 Notion 접근이 어려운 멤버에게 평가서 공통양식 또는 JSON 제출양식을 전달한다.
3. 각 평가자는 독립적으로 점수를 작성한다.
4. 비티가 평가 결과 DB에 수집한다.
5. 빌이 종합 분석 초안을 작성한다.
6. 라이언이 최종 승인한다.
7. 비티가 Notion에 최종 반영한다.
