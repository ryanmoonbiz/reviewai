# 📊 RAI_SCRUM_BACKLOG_RULES.md (스크럼 백로그 및 노션 상태 규칙)

본 문서는 노션(Notion) 스프린트 백로그 DB의 투명한 운영 및 상태 추적을 위한 갱신 원칙을 정의합니다.

---

## 1. 노션 기록 필수 항목
모든 작업이 진행 중이거나 완료될 때, 관련 백로그 페이지 본문에 아래 항목을 구조화하여 반드시 기록해야 합니다. 이전 기록은 절대 덮어쓰지 말고, **[제목 토글3] 진행사항-N** 순번으로 아래에 지속 누적합니다.

### [진행사항 템플릿]
* **작업 일시**: 작업이 이루어진 실제 시간 (KST 기준)
* **작업명**: 해당 작업 단계 및 버전 정보
* **최종 산출물 경로**: 로컬 및 GitHub 파일/브랜치 경로
* **반영한 수정사항**: (예: UI 텍스트 변경, CSS 버그 픽스 등)
* **검수 결과**: 비티 1차 QA 통과 여부 및 빌/라이언 피드백 반영 상태
* **남은 이슈**: 후속 작업이나 의존성 있는 태스크 항목
* **다음 액션**: 다음 스프린트 및 개발자의 할 일
* **빌/라이언 승인 여부**: 최종 컨펌 서명 상태

### [Notion 마크업 스타일 가이드]
1. **제목 2 (heading_2) 컬러 제한**: 제목 2를 쓸 때는 Notion block color(블록 색상)를 지정하지 않고 기본색(`default`)을 사용합니다. 컬러는 오직 `주의`, `확인`, `검토`, `중요` 가 필요하여 시각적 강조가 필요할 때만 예외적으로 사용합니다.
2. **불릿 리스트 (bulleted_list_item) 중복 기호 금지**: Notion 자체의 불릿 기호(머리말 기호)가 기본으로 렌더링되므로, 리스트 텍스트의 시작이나 bold prefix 내에 `-` 또는 `*` 등의 중복 기호를 절대 사용하지 않습니다. (예: `• - 남은 이슈:` ❌ -> `• 남은 이슈:` ⭕)

## 2. 스크럼 상태 변경 기준
노션 스프린트 백로그 DB의 `스크럼 상태` 속성은 아래의 정의에 맞추어 엄격하게 통제됩니다.

| 상태명 | 정의 및 전이 조건 | 관리 책임자 |
| :--- | :--- | :--- |
| **Product Backlog** | 아직 현 스프린트에 포함되지 않은 기능 후보 및 백로그 | 빌 (Bill) |
| **Sprint Backlog** | 이번 스프린트에서 해결하기로 확정되어 할당된 태스크 | 비티 (Biti) |
| **In Progress** | 덱스(Dex) 또는 관리 에이전트가 실제 작업 중인 상태 | 덱스 (Dex) / 비티 (Biti) |
| **Review** | 개발 및 1차 QA가 완료되어 빌/라이언 검토를 대기 중인 상태 | 비티 (Biti) |
| **Done** | **라이언의 최종 서명/컨펌이 확인**되어 완전히 완료된 상태 (라이언 서명 완료 전 Done 처리 금지) | 라이언 (Ryan) |
| **Blocked** | 기획 예외, 플랫폼 정책 리스크 등으로 인해 작업이 중단된 상태 | 비티 (Biti) |

## 3. 노션 및 API 키 보안 관리 규칙
* **토큰 유출 방지**: 노션 본문, PR 로그, 실행 결과 보고 텍스트 등 어떠한 곳에도 실제 Notion API Token(`ntn_...`)을 직접 노출하지 않습니다.
* **로그 마스킹**: curl 명령어 출력, config 파일, .env 파일 등 모든 실행 로그에서 노션 및 외부 API의 중요 키 값은 반드시 `****MASKED****` 처리하여 출력합니다.
