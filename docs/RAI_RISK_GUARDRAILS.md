## 2. AI 답글 가드레일 (민감 표현 감지)
사용자에게 제공되는 AI 답글 초안 중 특정 민감 단어 또는 공격적 표현이 감지될 경우, 시스템적으로 가드레일 배지 UI를 노출하여 사장님의 직접 검수를 강력히 유도합니다.

* **5대 위험 표현군 필터링 가이드**:
  1. 법적 분쟁 소지가 있는 단어 (예: 고소, 고발, 법적 대응)
  2. 고객을 직접적으로 비난하거나 조롱하는 단어
  3. 무조건적인 현금성 보상이나 무리한 약속 (예: 전액 환불 약속, 즉시 보상)
  4. 비속어, 비하성 어조, 방어적이거나 과도하게 해명하는 문구
  5. 무대응에 가까운 단순 반복 매크로성 답변
* **가드레일 UI 사양**:
  * 해당 답글 초안 우측 상단 또는 하단에 `[민감 표현 감지 - 수동 검수 필수]`라는 명확한 빨간색/주황색 배지 UI 노출.

## 3. Blocked 상황 에스컬레이션 경로
기획 변경이나 기술적 한계에 부딪힐 때 에이전트(Biti, Dex)는 다음 절차에 의거하여 즉시 이슈를 에스컬레이션해야 합니다.

1. **상태 변경**: 백로그 `스크럼 상태`를 `Blocked`로 변경.
2. **원인 기록**: 비티가 직면한 리스크 유형(비용, 정책, 기술, 데이터 구조 등)과 대안 옵션 2~3가지를 기술.
3. **리드진 검토**: 빌이 사업적 영향도를 분석하고 라이언이 최종 결정을 승인할 때까지 작업 중단을 유지.
