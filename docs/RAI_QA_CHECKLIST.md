# 🧪 RAI_QA_CHECKLIST.md (QA 및 검수 가이드라인)

본 문서는 리뷰와이(Reviewai) MVP 단계의 신뢰성과 사용자 경험을 보장하기 위해 비티(Biti)가 수행해야 할 QA 검수 기준 및 체크리스트를 규정합니다.

---

## 1. 1차 QA 핵심 점검 영역
* **화면 레이아웃 및 반응형 디자인**: 모바일 및 데스크톱 브라우저 환경에서 CSS 그리드/플렉스박스 레이아웃의 깨짐 현상이 없는지 확인합니다.
* **사용자 입력 예외 처리**: 사용자가 리뷰 텍스트를 비워두거나, 잘못된 형식의 CSV를 업로드할 때의 적절한 에러 핸들링과 UI 피드백을 검증합니다.
* **텍스트 복사 및 조작 기능**: 클립보드 복사 버튼 클릭 시, 텍스트가 정확히 복사되는지 브라우저에서 직접 테스트합니다.

---

## 2. 세부 기능별 QA 체크리스트

### [체크리스트 1] 수동 입력 및 CSV 업로드 (`RAI-S2-ST03`)
* [ ] 직접 텍스트를 복사-붙여넣기 할 수 있는 Text-area 폼이 정상 동작하는가?
* [ ] CSV 파일 드롭존이 파일 첨부를 감지하고, CSV 파서가 올바르게 작동하는가?
* [ ] 파싱 시 필수 컬럼(`reviewText`, `rating`)이 누락되었을 때 명확한 안내 팝업이 노출되는가?
* [ ] CSV 템플릿 다운로드 기능이 정상 작동하며, 템플릿 컬럼 구성이 올바른가?

### [체크리스트 2] 리뷰 개수 100개 제한 검증 (`RAI-S2-ST04`)
* [ ] 입력된 리뷰 데이터의 총개수가 100개 이하일 때 분석 대기 화면으로 정상 진행되는가?
* [ ] 리뷰가 100개를 초과할 때(예: 101개 이상) 분석 진행이 차단되는가?
* [ ] 차단 시 **'1:1 추가 상담 및 견적 안내'** 팝업이 띄워지며, 카카오톡 1:1 채널 이동 CTA 버튼이 보이는가?

### [체크리스트 3] 리포트 결과 화면 및 탭 플로우 (`RAI-S2-ST05 ~ ST09`)
* [ ] `/report` 단일 대시보드 내에서 3개의 내부 탭이 문제없이 전환되는가?
  * `[탭 1] 분석 결과 요약` (별점 분포, 반복 불만 TOP 5, 위험 리뷰 리스트)
  * `[탭 2] AI 답글 초안` (4가지 브랜드 톤별 답글 리스트, 클립보드 복사)
  * `[탭 3] 상세페이지 개선 제안` (상세페이지/FAQ 개선 팁 카드, 추가 상담 CTA)
* [ ] 탭 2에서 **'민감 표현 감지 - 수동 검수 필수'** 경고 배지 UI가 5대 위험 표현군 필터링 시 올바르게 노출되는가?
* [ ] 브라우저 인쇄 단축키(`Ctrl+P` / `Cmd+P`) 사용 시, 리포트 영역만 깨끗하게 출력되는 인쇄 친화형 CSS 디자인이 적용되었는가?

## 3. 금지 문구 및 가드레일 QA
다음과 같은 마케팅/기획 금지 사항이 프론트엔드 화면이나 UI 텍스트에 포함되어 있지 않은지 최종 배포 전에 전수 검사합니다:
* `자동수집 보장` (우리는 복사-붙여넣기 및 CSV 방식만 제공합니다)
* `자동답글 게시 보장` (사용자가 직접 복사해서 활용해야 합니다)
* `평점 상승 보장` / `AI 검색 노출 보장`
* `허위 리뷰 단정` (허위 리뷰 가능성 또는 분석 기준만을 제공합니다)
