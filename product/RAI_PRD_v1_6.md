# 📄 RAI_PRD_v1_6.md (제품 요구사항 정의서) v1.6

본 문서는 리뷰와이(Reviewai) MVP 단계의 구현 기준이 되는 제품 요구사항 정의서(PRD) v1.6 초안입니다. 스프린트 2(S2) scaffold 진입 및 덱스(Dex)의 개발 실행 시 기능의 명확한 범위(Scope)와 완료 조건으로 사용됩니다.

---

## 1. 제품 개요 및 비즈니스 목적
* **제품명**: 리뷰와이 (Reviewai) — 사장님 리뷰비서
* **제품 비전**: 이커머스 사장님들이 리뷰 데이터를 복사-붙여넣기 및 CSV 업로드를 통해 쉽고 빠르게 분석하여, 브랜드 평판 위험 신호를 사전에 진지하게 파악하고 맞춤형 고객 답글 및 상세페이지 교정 포인트를 획득할 수 있도록 돕는 솔루션입니다.
* **MVP 핵심 과제**: 최대 100개 리뷰 분석 제약을 적용한 **'49,000원 리뷰 진단 리포트 상품'**의 가치 실현 및 Mock data 기반 UI 완성.

---

## 2. 사용자 핵심 플로우 (User Journey)
1. **홈/소개 (`/`)**: 사장님이 랜딩 페이지에 유입되어 49,000원 리뷰 진단 리포트 상품의 혜택 및 샘플 보고서를 확인합니다.
2. **입력 화면 (`/submit`)**: 사장님이 스토어명, 상품명을 작성하고 리뷰 텍스트를 붙여넣거나 CSV 파일을 첨부합니다.
3. **제한 및 처리**: 100개 이하일 경우 로딩 페이지(`/analysis/progress`)를 거쳐 리포트로 진입하며, 100개 초과 시 견적 안내/상담 팝업을 노출합니다.
4. **리포트 조회 (`/report`)**: 분석 결과 요약, AI 답글 초안, 상세페이지 개선 제안 탭을 오가며 분석된 결과물과 위험 신호를 조회하고 답글을 복사하여 쇼핑몰에 직접 등록합니다.

---

## 3. 기능적 요구사항 (System Specifications)

### 3.1. 리뷰 데이터 입력 및 파싱 (`In-Scope`)
* **직접 복사-붙여넣기**: 대용량 Textarea를 통해 원본 리뷰 텍스트를 줄바꿈 단위로 입력받습니다.
* **CSV 파일 드롭존**: 드래그 앤 드롭 또는 파일 선택을 통해 `.csv` 파일을 업로드합니다.
  * **필수 파싱 컬럼**: `reviewText` (리뷰 본문), `rating` (별점: 1~5 정수)
  * **선택 파싱 컬럼**: `date` (작성 날짜), `options` (선택 옵션)
  * **오류 처리**: 필수 컬럼 누락 시 업로드를 중단하고 경고 창(`Alert`)을 표시합니다.
* **템플릿 다운로드**: 필수/선택 컬럼이 기입된 예제 `sample_review_template.csv`를 다운로드할 수 있는 링크를 제공합니다.

### 3.2. 입력 개수 제약 로직
* **100개 한계선**: 입력된 행(Row) 수가 100개 이하일 때만 리포트 화면으로 진입할 수 있습니다.
* **초과 예외 처리**: 101개 이상 유입 시 즉시 분석을 중단하며, **"1:1 추가 상담 및 정밀 진단 리포트 견적 안내"** 팝업을 모달로 띄워 카카오톡 1:1 채널 상담 CTA 버튼을 노출합니다.

### 3.3. 통합 리포트 대시보드 (`/report` 내부 탭 구조)
* **[탭 1] 분석 결과 요약**
  * **기본 지표**: 총 리뷰 수, 평균 별점, 별점 하락 우려 신호 경고 배지(평균 3.5 이하 등 특정 조건 만족 시 노출).
  * **부정 위험 리뷰**: 별점 1~2점 및 불만 단어가 포함된 리뷰 중 최우선 대응이 필요한 카드를 리스트로 제공.
  * **반반 키워드 분석**: 긍정 키워드 5개 / 부정 키워드 5개를 추출하여 빈도 순위 노출.
* **[탭 2] AI 답글 초안**
  * **4대 브랜드 톤 설정**: 친절한 사장님형, 전문 브랜드형, 담백한 CS형, 재방문 유도형 탭 전환 지원.
  * **답글 추천**: 선택된 톤에 매칭되는 답글 초안 3종 제시.
  * **가드레일 필터링**: 법적 위협, 무조건적 환불 확답 등 민감 표현 감지 시 **[민감 표현 감지 - 수동 검수 필수]** 경고 배지 표출.
  * **클립보드 복사**: 단일 클릭으로 답변 텍스트를 기기 클립보드에 바로 복사.
* **[탭 3] 상세페이지 개선 제안**
  * **개선 제안 카드**: 고객 불만 키워드 분석에 근거해 상세페이지의 설명 보완 포인트(예: 사이즈 교정 팁 등) 제공.
  * **종료/상담 CTA**: "월간 리뷰 관리 케어팩" 상담 및 1:1 결제 유도를 위한 카카오톡 상담 채널 이동 링크 배너 노출.

## 4. 비기능적 요구사항 & 제약 사항 (`Out-of-Scope`)
* **크롤링 및 자동 수집 배제**: 셀러 계정 연동이나 로그인, CAPTCHA 우회 등을 활용한 크롤링은 보안 및 법적 분쟁을 방지하기 위해 완전히 배제합니다. (오직 CSV 및 복붙 입력만 지원)
* **자동 답글 즉시 발행 금지**: 사장님이 톤을 검증한 뒤 직접 쇼핑몰에 복사-붙여넣기 하도록 유도하며, API를 통한 답글 직접 게시는 허용하지 않습니다.
* **PDF 자동 변환 배제**: 서버 사이드 PDF 생성이나 다운로드 모듈은 제외하며, 브라우저 기본 인쇄 기능(`Cmd+P`)을 지원하는 미디어 쿼리 CSS 레이아웃으로 대체합니다.
* **Mock 데이터 기반 우선**: 스프린트 2에서는 Gemini API 실제 호출 연동 없이 로컬 Mock JSON 데이터를 바인딩하여 UI 구성요소를 완성하는 데 집중합니다.

## 5. UI 라우팅 테이블
* `/` : 서비스 소개 및 진입 경로
* `/submit` : 상품 정보 기입, 텍스트 복붙 영역, CSV 파일 드롭존
* `/analysis/progress` : 분석 대기 애니메이션 및 안내 페이지
* `/report` : 통합 리포트 대시보드 (탭 1, 2, 3 전환식 구성)
